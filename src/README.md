# EMACS Environment
> [IMPORTANT!] This Repo is Partially maintained and only tested on mac
> This was supposed to be a reproducible emacs environment regardless of windows, mac or linux distro
> However, nuances in Operating Systems caused problems, so this is a work in progress 

# Things to Note
- Windows doesn't properly support emacs without gtk 
- WSL yields no better results (unless you're on Win11 where wsl commands can launch GUI apps)
- Linux distros like nix prefer you grab emacs pkgs thru it's declarative nix pkg mgr
- Use Environment vars to boot into your preferred environment
